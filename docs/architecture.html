A caveat that belongs on the diagram.

The mean-pool stage collapses the 30-frame axis before either head runs, so the "RNN" receives a sequence over feature indices, not over time. This pipeline compares two classifier heads on an identical pooled vector — it is not a fair test of convolution versus recurrence. The un-pooled (30, 1280) tensors are now saved so a genuine temporal model can be trained later.
